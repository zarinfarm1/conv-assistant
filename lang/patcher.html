📖 راهنمای پچ (چیست و چطور نوشته می‌شه)
انواع عملیات:
  1. replace — جایگزینی یک anchor
  2. replace-between — جایگزینی از شروع تا پایان (برای بلوک‌های بزرگ)
  3. insert-before — اضافه کردن قبل از anchor
  4. insert-after — اضافه کردن بعد از anchor
  5. append — اضافه کردن به آخر فایل
  6. regex — جایگزینی با regex (پیشرفته)
نمونه: 
{
  "patches": [
    {"op": "replace", "anchor": "old text", "content": "new text"},
    {"op": "insert-before", "anchor": "// MARKER", "content": "// new code\n"},
    {"op": "append", "content": "// end code"}
  ]
}
